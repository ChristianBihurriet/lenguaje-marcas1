# 01 · Explorar una página HTML

## Objetivo

Reconocer las partes principales de un documento HTML y comprobar cómo los cambios en el archivo se reflejan en el navegador.

**Tiempo orientativo:** 30 minutos  
**Archivo que debes editar:** `index.html`

## Antes de empezar

Una **etiqueta** indica qué función tiene cada contenido. Por ejemplo, unas etiquetas sirven para crear encabezados y otras para crear párrafos. Los comentarios escritos entre `<!--` y `-->` son notas para quien lee el código: el navegador no los muestra en la página.

## Instrucciones

1. Abre `index.html` en Visual Studio Code y abre ese mismo archivo en el navegador.
2. Localiza en el código el texto que aparece como título de la pestaña. Después localiza el encabezado grande que se ve dentro de la página.
3. Cambia el nombre de la estudiante ficticia por el tuyo y adapta el párrafo de presentación.
4. Modifica los elementos de la lista para que indiquen cosas que te gustaría aprender.
5. Guarda el archivo y recarga la página en el navegador. Repite el proceso con algún cambio pequeño más.

## Resultado esperado

La página seguirá mostrando un encabezado, varios textos y una lista, pero ahora incluirá tu nombre, tu presentación y tus intereses.

## Comprueba que lo entiendes

¿Qué parte del documento cambia el texto de la pestaña y cuál cambia el encabezado visible?

## Reto opcional

Añade un nuevo párrafo al final de la página para contar qué programa utilizas más en tu ordenador.
