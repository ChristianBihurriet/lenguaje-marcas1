# 05 · Mi primera página

## Objetivo

Crear de forma autónoma una ficha personal sencilla aplicando lo practicado en los ejercicios anteriores.

**Tiempo orientativo:** 55 minutos  
**Archivo que debes editar:** `index.html`

## Instrucciones

1. Abre `index.html`. La estructura básica ya está preparada y el cuerpo está vacío para que construyas tu ficha.
2. Cambia el título de la pestaña por uno relacionado con tu página.
3. Añade un encabezado principal `h1` con tu nombre.
4. Organiza la ficha con dos secciones y sus correspondientes encabezados `h2`.
5. Escribe varios párrafos para presentarte y contar algo sobre cada sección.
6. Incluye una lista con información que tenga sentido en tu ficha.
7. Añade un enlace con texto descriptivo.
8. Muestra la imagen `imagenes/aula.svg` e incluye una alternativa textual que explique su contenido.
9. Guarda, abre la página en el navegador y revísala con la lista de comprobación.

## Lista de comprobación

- [ ] La pestaña tiene un título relacionado con la página.
- [ ] Hay un solo encabezado principal `h1`.
- [ ] Hay dos secciones identificadas con `h2`.
- [ ] La ficha contiene párrafos y una lista.
- [ ] El enlace tiene un texto que explica adónde lleva.
- [ ] La imagen se muestra y tiene una alternativa textual útil.
- [ ] Las etiquetas están correctamente anidadas y cerradas.
- [ ] He guardado el archivo y he recargado el navegador.

## Resultado esperado

Obtendrás una página personal pequeña pero completa, con contenido bien organizado, un enlace funcional y una imagen local.

## Comprueba que lo entiendes

¿Cómo decides si un texto debe ser un encabezado, un párrafo o un elemento de lista?

## Reto opcional

Añade una tercera sección sobre algo que quieras aprender este curso y destaca una idea importante dentro de uno de sus párrafos.
