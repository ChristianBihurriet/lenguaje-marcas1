# 02 · Completar la estructura

## Objetivo

Construir la estructura mínima de un documento HTML siguiendo las indicaciones de una plantilla.

**Tiempo orientativo:** 25 minutos  
**Archivo que debes editar:** `index.html`

## Vocabulario

- La **declaración doctype** informa al navegador de que el documento usa HTML actual.
- `html` es el elemento raíz: contiene todos los demás elementos.
- `head` reúne información para el navegador, como la codificación y el título de pestaña.
- `body` contiene la información visible de la página.
- **Anidar** significa colocar un elemento dentro de otro respetando el orden de apertura y cierre.

## Instrucciones

1. Abre `index.html` y lee todos los comentarios `TODO` antes de escribir.
2. Añade la declaración que identifica el documento como HTML.
3. Crea el elemento raíz e indica que el idioma del contenido es español.
4. Dentro de él, crea la zona de información del documento. Indica la codificación UTF-8 y escribe un título de pestaña relacionado con Lucía.
5. Crea la zona de contenido visible con un encabezado principal y un párrafo breve de presentación.
6. Añade todos los cierres necesarios y revisa que cada elemento esté dentro de la parte correcta.
7. Guarda el archivo y ábrelo en el navegador.

## Resultado esperado

El navegador mostrará una página pequeña con un encabezado y un párrafo. La pestaña tendrá su propio título y los caracteres españoles se verán correctamente.

## Comprueba que lo entiendes

¿Por qué el contenido de `head` y el de `body` cumplen funciones distintas?

## Reto opcional

Cuando la estructura funcione, añade un segundo párrafo dentro de la zona visible sin cambiar el resto del documento.
