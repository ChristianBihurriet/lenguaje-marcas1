# 04 · Encontrar y corregir errores

## Objetivo

Practicar la lectura cuidadosa de HTML, localizar problemas de marcado y comprobar cada corrección en el navegador.

**Tiempo orientativo:** 55 minutos  
**Archivo que debes editar:** `index.html`

## Instrucciones

1. Abre `index.html` en Visual Studio Code y en el navegador.
2. Lee el documento despacio desde el principio hasta el final.
3. Localiza los problemas de estructura, contenido y rutas. Corrígelos de uno en uno.
4. Después de cada cambio, guarda y recarga el navegador para observar el resultado.
5. Comprueba que el título de la pestaña sea adecuado para la ficha de la estudiante.
6. Revisa al final el documento completo. Si quieres una comprobación adicional, puedes pegar tu código en el [validador de HTML](https://validator.w3.org/nu/).

## Pistas generales

- Las etiquetas de apertura y cierre deben corresponderse.
- Los elementos anidados se cierran en el orden inverso al que se abren.
- Una lista necesita elementos que identifiquen cada opción.
- Las rutas relativas parten de la ubicación del archivo HTML.
- El título de la pestaña debe ser informativo.

## Resultado esperado

La página conservará la ficha personal original, pero el documento tendrá un marcado coherente, la lista estará bien formada, la imagen se mostrará y la pestaña tendrá un título apropiado.

## Comprueba que lo entiendes

¿Por qué una página puede llegar a verse en el navegador aunque su marcado contenga errores?

## Reto opcional

Cuando hayas terminado, intercambia el archivo con un compañero o compañera y explica cómo comprobaste una de tus correcciones sin indicar de antemano dónde estaba el problema.
