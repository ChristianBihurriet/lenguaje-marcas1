# 03 · Añadir contenido

## Objetivo

Completar una página ya estructurada con distintos tipos de contenido HTML.

**Tiempo orientativo:** 55 minutos  
**Archivo que debes editar:** `index.html`

## Vocabulario

- Los encabezados `h1` y `h2` organizan el contenido por niveles.
- `strong` señala un fragmento que tiene especial importancia.
- Un **enlace** lleva a otra página y combina una dirección con un texto descriptivo.
- Una imagen local se carga desde un archivo del proyecto mediante `src`; `alt` ofrece una alternativa textual que explica la imagen.

La imagen que usarás ya está preparada en `imagenes/aula.svg`. No necesitas abrirla ni editarla.

## Instrucciones

1. Abre `index.html` y localiza los comentarios `TODO` del cuerpo del documento.
2. Escribe tu nombre como encabezado principal `h1`.
3. Crea dos secciones con encabezados `h2`: “Sobre mí” y “Aficiones”.
4. Añade párrafos que presenten a la estudiante ficticia y expliquen sus intereses.
5. Crea una lista con tres aficiones.
6. Marca como importante un fragmento breve usando `strong`.
7. Añade un enlace a Wikipedia. Usa un texto descriptivo que permita saber adónde lleva el enlace.
8. Muestra la imagen local `imagenes/aula.svg` e incluye una alternativa textual útil con el atributo `alt`.
9. Guarda el archivo, ábrelo en el navegador y comprueba todo el contenido.

## Resultado esperado

La página mostrará una ficha legible, dividida en secciones, con textos, tres aficiones, un fragmento importante, un enlace descriptivo y la imagen del aula.

## Comprueba que lo entiendes

¿Qué información aporta `alt` cuando una imagen no puede verse?
