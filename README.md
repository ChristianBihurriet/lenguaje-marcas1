# Lenguajes de Marcas · Clase 01

Este repositorio contiene el material de la primera clase de **Lenguajes de Marcas de 1.º DAM**. Está pensado para empezar desde cero: observarás páginas pequeñas, modificarás archivos y escribirás tus primeras etiquetas HTML.

## Qué aprenderás

- Qué partes básicas tiene un documento HTML.
- La diferencia entre el título de la pestaña y el contenido visible de una página.
- Cómo usar encabezados, párrafos, listas, enlaces, texto destacado e imágenes.
- Cómo detectar algunos errores frecuentes de marcado.
- Cómo crear una página personal sencilla.

No necesitas instalar extensiones, programas adicionales ni dependencias. Solo usarás Visual Studio Code y un navegador.

## Preparación

### 1. Clona el repositorio

Abre una terminal y ejecuta:

```text
git clone <URL_DEL_REPOSITORIO>
```

### 2. Abre la carpeta en Visual Studio Code

En Visual Studio Code, elige **Archivo → Abrir carpeta…** y selecciona `dam-lenguajes-marcas-clase-01`.

En el explorador lateral verás una carpeta por ejercicio. Cada una contiene su propio `README.md` con las instrucciones.

### 3. Abre una página en el navegador

Empieza en `01-explorar`. Busca su archivo `index.html` en el explorador de archivos de tu equipo y ábrelo con un doble clic. También puedes usar la opción **Abrir con** y elegir tu navegador.

No hace falta iniciar un servidor: todos los ejemplos funcionan abriendo el archivo HTML directamente.

## El ciclo de trabajo

Durante la clase repetirás estos tres pasos:

1. **Editar** `index.html` en Visual Studio Code.
2. **Guardar** el archivo (`Ctrl+S` o `Cmd+S`).
3. **Recargar** la página en el navegador para ver el cambio.

Si el navegador no muestra lo que esperabas, comprueba primero que has guardado el archivo y recarga de nuevo.

## Orden recomendado

La clase está organizada en cuatro bloques de 55 minutos:

1. **Bloque 1:** `01-explorar` para reconocer una página que ya funciona y `02-estructura` para completar su esqueleto.
2. **Bloque 2:** `03-contenido` para añadir distintos tipos de contenido.
3. **Bloque 3:** `04-corregir` para buscar y corregir errores intencionales.
4. **Bloque 4:** `05-mi-pagina` para crear tu primera ficha personal.

Lee el `README.md` de cada carpeta antes de tocar su `index.html`. Algunas plantillas están incompletas a propósito y el cuarto ejercicio contiene errores intencionales. No los confundas con fallos de descarga.

Tus cambios son para practicar en tu copia local. **No necesitas hacer commits ni subirlos a ningún sitio.**

## Vocabulario inicial

- **HTML**: lenguaje de marcado que indica la estructura y el significado del contenido de una página.
- **Elemento**: una parte del documento, como un encabezado, un párrafo o una lista.
- **Etiqueta**: marca escrita entre los signos `<` y `>` que sirve para crear un elemento.
- **Atributo**: información adicional escrita en la etiqueta de apertura, por ejemplo el idioma de una página.
- **Navegador**: programa que interpreta el HTML y muestra la página.
